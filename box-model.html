O que é o Box Model?

Todo elemento HTML é representado como uma caixa retangular no CSS. O Box Model define como o navegador calcula o tamanho e o espaçamento dessas caixas.

O modelo é composto por quatro partes principais:

  • Content — o conteúdo em si (texto, imagem, etc.);
  • Padding — o espaço interno entre o conteúdo e a borda;
  • Border — a borda que envolve o padding e o conteúdo;
  • Margin — o espaço externo entre o elemento e outros elementos.

Componentes do Box Model

1. Content

É o conteúdo real dentro do elemento — como texto, imagens ou outros elementos filhos. É definido pelo width e height.

2. Padding

É o espaço entre o conteúdo e a borda. Define uma “folga interna” dentro do elemento. Exemplo: padding: 20px;

3. Border

É a borda que envolve o conteúdo e o padding. Pode ter cor, espessura e estilo (ex: solid, dashed, double).

4. Margin

É o espaço externo entre o elemento e o que está ao redor. Exemplo: margin: 15px;

Dica Extra

Para facilitar o controle do tamanho total de um elemento (incluindo bordas e padding), podemos usar: 

box-sizing: border-box;

Isso faz com que o width e height incluam o padding e a borda no cálculo total.
