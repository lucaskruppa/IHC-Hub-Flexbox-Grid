O que é o CSS Grid

O CSS Grid é um modelo de layout bidimensional: ele organiza os elementos em linhas e colunas ao mesmo tempo. O Flexbox organiza os itens em uma direção por vez, mas o Grid primeiro desenha a grade. Depois, posiciona os itens nas células.

Para usar o Grid, é preciso conhecer estes termos:

  • Container grid: o elemento pai, que recebe display: grid;.
  • Itens grid: os filhos diretos do container.
  • Coluna: divisão vertical da grade.
  • Linha: divisão horizontal da grade.
  • Célula: o encontro de uma linha com uma coluna.

Exemplo 1: grade básica

Com display: grid, o container vira uma grade. As colunas são definidas com grid-template-columns e as linhas com grid-template-rows.

O CSS essencial desta demonstração:

.grade-basica {
                display: grid;
                grid-template-columns: repeat(3, 1fr);
                grid-template-rows: repeat(2, 80px);
                gap: 15px;
            }
  • repeat(3, 1fr): três colunas de tamanhos iguais. A unidade fr é uma fração do espaço livre do container.
  • repeat(2, 80px): duas linhas, cada uma com 80px de altura.
  • gap: espaço entre as células, o mesmo do Flexbox.

Repare que os itens não têm largura nem altura definidas: quem define o tamanho de cada um é a célula da grade onde ele está.

Exemplo 2: tamanhos diferentes e itens maiores

As colunas podem misturar tamanhos fixos, como px, e tamanhos flexíveis, como fr. A coluna fixa mantém o seu tamanho, e o espaço que sobra é dividido entre as colunas em fr, na proporção dos números.

Um item também pode ocupar mais de uma célula. Para isso usamos grid-column e grid-row, que trabalham com as linhas de grade: os traços numerados que separam as colunas e as linhas da grade.

O CSS essencial desta demonstração:

.grade-tamanhos-diferentes {
                display: grid;
                grid-template-columns: 100px 1fr 2fr;
                grid-template-rows: repeat(3, 70px);
                gap: 15px;
            }

            .item-grid-ocupa-duas-colunas {
                grid-column: 1 / 3;
            }

            .item-grid-ocupa-duas-linhas {
                grid-row: span 2;
            }
  • 100px 1fr 2fr: a primeira coluna tem 100px fixos. O espaço restante é dividido em 3 partes: a segunda coluna fica com 1 parte e a terceira com 2 partes.
  • grid-column: 1 / 3: o item começa na linha 1 e termina na linha 3, ocupando as colunas 1 e 2.
  • grid-row: span 2: o item ocupa duas linhas a partir da posição em que a colocação automática o colocar.
  • Os demais itens não têm posição definida: o navegador os coloca na próxima célula livre, na ordem do HTML.

Exemplo 3: layout de página com áreas

Outra forma de posicionar itens é dar nome às regiões da grade com grid-template-areas. Cada texto entre aspas representa uma linha da grade, e cada palavra dentro dele representa uma coluna. Repetir o mesmo nome em células vizinhas faz essas células virarem uma única área.

cabeçalho
menu
conteúdo
rodapé

O CSS essencial desta demonstração:

.layout-de-pagina {
                display: grid;
                grid-template-columns: 150px 1fr;
                grid-template-rows: 60px 150px 50px;
                grid-template-areas:
                    "cabecalho cabecalho"
                    "menu conteudo"
                    "rodape rodape";
                gap: 15px;
            }

            .area-cabecalho { grid-area: cabecalho; }
            .area-menu { grid-area: menu; }
            .area-conteudo { grid-area: conteudo; }
            .area-rodape { grid-area: rodape; }
  • Há três textos entre aspas, então a grade tem três linhas. Cada texto tem duas palavras, então a grade tem duas colunas.
  • Em "cabecalho cabecalho", o nome se repete: o cabeçalho ocupa as duas colunas da primeira linha. O rodapé faz o mesmo na última linha.
  • grid-area: cabecalho manda o item para a área com esse nome.
  • Cada área precisa formar um retângulo.
  • A ordem dos itens no HTML não importa: cada um vai para a sua área, ao contrário da colocação automática do exemplo 2.
