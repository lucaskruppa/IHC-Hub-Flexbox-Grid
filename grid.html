O que é o CSS Grid

O CSS Grid é um modelo de layout bidimensional: ele organiza os elementos em linhas e colunas ao mesmo tempo. O Flexbox organiza os itens em uma direção por vez, mas o Grid primeiro desenha a grade. Depois, posiciona os itens nas células.

Para usar o Grid, é preciso conhecer estes termos:

  • Container grid: o elemento pai, que recebe display: grid;.
  • Itens grid: os filhos diretos do container.
  • Coluna: divisão vertical da grade.
  • Linha: divisão horizontal da grade.
  • Célula: o encontro de uma linha com uma coluna.

Exemplo 1: grade básica

Com display: grid, o container vira uma grade. As colunas são definidas com grid-template-columns e as linhas com grid-template-rows.

O CSS essencial desta demonstração:

.grade-basica {
                display: grid;
                grid-template-columns: repeat(3, 1fr);
                grid-template-rows: repeat(2, 80px);
                gap: 15px;
            }
  • repeat(3, 1fr): três colunas de tamanhos iguais. A unidade fr é uma fração do espaço livre do container.
  • repeat(2, 80px): duas linhas, cada uma com 80px de altura.
  • gap: espaço entre as células, o mesmo do Flexbox.

Repare que os itens não têm largura nem altura definidas: quem define o tamanho de cada um é a célula da grade onde ele está.
